# Math practice pages

Seven short practice pages for trig and algebra foundations. Each page keeps its own practice record in the browser, on the device, under its Report tab. Nothing is sent anywhere.

- `index.html` lists the pages.
- `src/` holds the sources. `build.py` builds a page from `<name>.page.html` plus the shared `kit.css` and `kit.js`. `site.py` wraps the built pages into the standalone files at the top level.
